# 超星学习通自动考试脚本
考试脚本：[chaoxing-exam.user.js](chaoxing-exam.user.js)<br>
部分代码由AI辅助完成<br>
自动完成超星学习通上期末考试的油猴脚本，使用AI答题<br>
使用前需安装**篡改猴/篡改猴测试版**

## 使用方法：
### 1.从Edge/Chorme的插件市场安装篡改猴

### 2.根据指示给予篡改猴浏览器权限

### 3.下载需要的脚本后将.user.js拖入篡改猴中，安装后即可使用

### 4.配置
`Base Url`<br>
常用base_url：
- OpenAI: `https://api.openai.com/v1`
- DeepSeek: `https://api.deepseek.com/v1`
- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai/`
- Claude: `https://api.anthropic.com/v1`
- 阿里百炼通义: `https://dashscope.aliyuncs.com/compatible-mode/v1`
- 智谱GLM: `https://open.bigmodel.cn/api/paas/v4`
- 火山方舟: `https://ark.cn-beijing.volces.com/api/v3`

`AI Key`<br>
从对应平台的控制台获取 AI Key

`Model`<br>
选择可用的模型

`选择前等待`与`选择后等待`<br>
随机量
